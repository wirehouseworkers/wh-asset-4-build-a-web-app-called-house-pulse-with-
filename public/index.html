Companion MCP Server

House Pulse exposes an MCP (Model Context Protocol) server so any AI assistant — Claude, ChatGPT, or your own agent — can check what's due and mark tasks complete on your behalf.

{
  "mcpServers": {
    "house-pulse": {
      "url": "https://api.housepulse.app/mcp",
      "tools": [
        "get_due_tasks(month?: string)",
        "get_task_history(task_id: string)",
        "mark_task_done(task_id: string, completed_on?: date, photo_url?: string)",
        "get_home_profile()"
      ]
    }
  }
}
